# Maple Notes example

A fictional site for illustrating the plugin. The product, workflow, commands and artwork are made up.

From the plugin repository root:

```bash
npm ci
npm run demo
```

Open http://localhost:3012 and choose **Edit page**. Stop the local server with Ctrl+C.

This example uses the repository's installed dependencies and plugin source. It does not need an account or an external service. All SVG artwork is original sample material distributed under the repository's MIT license. It contains no real customer or product data.
