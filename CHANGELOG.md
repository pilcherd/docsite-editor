# Changelog

## 1.0.0 — 2026-11-16

Initial public release of Docsite Editor by pilcherd.

- Visual and markup editing with unsaved draft switching, live preview and source preservation.
- Editable tab groups with automatic standard theme imports.
- Static image folder browsing, search, uploads, captions and display sizing.
- Internal page-tree links and manually entered addresses.
- Page creation, front matter, site settings and stylesheet editing.
- Sidebar sections, labels, page insertion and drag-and-drop ordering.
- Preview-to-editor selection and independently collapsible side panels.
- Reviewed local Git commits, confirmed reverts with recovery copies and fast-forward-only pulls.
- Discovery of custom content paths, multiple documentation instances, localized and versioned content.
- Loopback-only local API, protected writes, revision checks and atomic saves.
- MIT license, third-party notices and independent branding.
- Fictional example site and six illustrated README walkthroughs.
